# 效能與準確率報告（Performance Report）

> ⚠️ **以下所有指標均基於程式產生之合成評估資料，非真實發票資料，僅供展示系統運作方式，不代表實際生產環境準確率。**
>
> 本系統目前**尚未使用任何真實企業發票資料進行訓練或驗證**。以下數字係以確定性假向量編碼器（`hashlib.md5` 雜湊 n-gram，詳見 `examples/run_evaluation.py` 中 `_fake_embed()`）搭配少量人工關鍵字原型，對程式產生的合成評估集進行實測，目的僅在驗證系統各模組（前處理、母版模型、個人化層、融合引擎、稅法合規、解釋模組）之間的資料流與計算邏輯可正確運作，**不代表正式訓練後模型於真實發票資料上的分類品質**。

## 一、分類指標（實測，非估算）

| 指標 | 數值 | 說明 |
|---|---|---|
| Top-1 準確率（Accuracy） | **0.7455**（164/220） | 預測科目與合成標籤完全相符之比例 |
| Macro-F1 | **0.7473** | 各科目 F1 分數之算術平均（未出現於真實或預測標籤中的類別已排除，避免除以零） |
| Top-3 準確率 | **0.9364**（206/220） | 合成標籤是否落在融合引擎回傳之前 3 名候選科目（`top_k_candidates`）內 |

## 二、預測效能（實測，非估算）

以 `time.perf_counter()` 對 220 次 `InvoiceClassifier.predict()` 呼叫逐一計時（單機、單執行緒，未使用批次或平行化）：

| 指標 | 數值 |
|---|---|
| 呼叫次數 | 220（遠高於規格要求之最少 100 次） |
| 平均預測時間 | **0.166 ms** |
| P95 預測時間 | **0.211 ms** |
| 最小預測時間 | 0.128 ms |
| 最大預測時間 | 0.581 ms |

說明：此效能數字反映的是「假向量編碼＋融合引擎＋稅法規則比對＋解釋組裝」全流程在單機 Python 環境下的計算開銷，**不包含**真實 Sentence Transformer 模型的推論時間（若未來啟用該後端並需連網下載模型權重，實際延遲將顯著提高，需另行實測）。

## 三、與 `tests/` 內效能測試的關係

`tests/test_fusion_engine.py::test_performance_under_one_second`、`tests/test_boundary_pytest.py::test_full_suite_completes_under_30_seconds` 等測試已驗證系統在測試資料規模下之效能下限（皆通過，詳見 `reports/test_report.md`）；本報告之數字為額外之獨立實測，樣本數與呼叫次數更高，用於呈現具體毫秒數字而非僅驗證「是否小於某門檻」。

## 四、結論與限制

1. 本報告所有數字均為 2026-09-01 實際執行 `examples/run_evaluation.py` 之輸出，非估算、非引用自其他專案或歷史紀錄。
2. 本系統**尚未於任何真實發票資料上進行訓練或驗證**；上述 accuracy / F1 / top-3 數字僅反映合成資料與簡化假向量編碼器組合下的系統行為，不應作為生產環境準確率的參考依據。
3. 正式上線前，應依 README 指示以真實（或至少更貼近真實分佈的）標註資料執行 `src/invoice_classifier/master_model.py` 之訓練流程，重新產生 `master_model.pkl`，並重新執行本評估腳本或建立更嚴謹的驗證集（含交叉驗證、時間切分等）。
4. 完整原始數據見 `reports/eval_results.json`（由 `examples/run_evaluation.py` 自動產生）。
